# RikyWave — кайфовый плеер (\*ˊᗜˋ\*)

Источник треков: **new.zvukofon.com** (парсер). Запасной вариант: Jamendo (`SOURCE=jamendo`).
Есть аккаунты (регистрация/вход): у каждого пользователя свои плейлисты, история прослушивания и история поисков. Всё хранится в `server/data.json`, пароли — хэшами (scrypt). Аудио играет через наш сервер (`/api/stream`).

Звуки интерфейса генерируются в браузере (client/src/sounds.js), кнопка «Звук» в меню включает и выключает их. 

## Запуск (´ω｀)

1\. Для работы требуется Node 18 или выше

2\. старт бэка: cd server \&\& npm install \&\& npm start     

3\. старт фронта: (другой терминал):  cd client \&\& npm install \&\& npm run dev

Если поиск пишет, что сайт отклонил запрос — он блокирует ваш IP: включите VPN или задайте PROXY\_URL в server/.env.
